# 📚 Process — Documentation de pilotage du projet

Ce dossier documente le **process de travail** sur le projet `myLaravelSkeleton` : comment lancer le projet, comment coder via BMAD, comment naviguer le quotidien dev.

> 💡 **Public visé** : Alex (dev solo) en priorité, et tout forker du skeleton OSS qui veut comprendre la méthodologie.

## 🎯 Quick start

Tu es Alex et tu veux **lancer / reprendre le projet** :

1. Lis [01-getting-started.md](01-getting-started.md) pour le setup machine + premier `make install-dev-full`
2. Lis [02-bmad-workflow.md](02-bmad-workflow.md) pour comprendre comment utiliser les skills BMAD pour coder
3. Référence : [`docs/roundtable-decisions.md`](../roundtable-decisions.md) pour le contexte des décisions stack & produit

Tu es un **forker** qui découvre le skeleton :

1. Lis le [README.md](../../README.md) racine pour la stack
2. Lis [01-getting-started.md](01-getting-started.md) pour le setup
3. Tu peux ignorer 02-bmad-workflow.md si tu n'utilises pas BMAD
