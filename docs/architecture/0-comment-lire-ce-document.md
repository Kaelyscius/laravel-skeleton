# 0. Comment lire ce document

Ce document **ne re-débat aucune décision**. Toutes les décisions sont gravées dans `roundtable-decisions.md`. Ici on **formalise comment elles s'incarnent** dans le code et l'infra.

| Tu cherches… | Section |
|---|---|
| Pourquoi telle décision a été prise | → `roundtable-decisions.md` |
| Comment elle s'implémente | → ici |
| Le contexte historique d'un choix structurant | → `docs/adr/ADR-XXXX-*.md` |
| Comment démarrer la machine | → `docs/process/01-getting-started.md` |
| Comment dérouler le workflow BMAD | → `docs/process/02-bmad-workflow.md` |
